# CampusApply

A polished, local-first application tracker for students managing internships and early-career roles. No account, backend, or API key required.

## Features
- Track company, role, status, application date, job link, and follow-up notes
- Search and filter applications, with newest/oldest sorting
- Dashboard counts for applications, in-progress applications, interviews, and offers
- Edit and delete records
- Export a JSON backup
- Responsive dark dashboard UI
- Data remains in browser `localStorage`

## Run locally
Open `index.html` in a modern browser. It is a static site and can also be hosted on GitHub Pages.

## Privacy
Application data is stored only in the browser on the current device. Clearing browser storage removes the data, so use Export data to keep a backup.
